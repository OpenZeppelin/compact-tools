## Unreleased

### Added

- `compact-mock` bin, a launcher that downloads the [`compact-mock`](https://github.com/OpenZeppelin/compact-tools/tree/main/crates/compact-mock) release binary for the host, verifies its SHA-256 against the package's `checksums.txt`, caches it, and runs it (#247)
- The `compact-mock` binary, a mock contract generator for Compact modules: `generate` writes the mocks `compact-mock.toml` describes, and `generate --check` exits 1 when a committed mock is missing or differs (#247)
- `compact-mock.toml`: one `[[mock]]` entry per module, a one-line minimum, with `exclude`, `disclose`, `guard`, `rename`, `init`, `ledger`, `module_args`, `circuit_args` and `out_dir` overrides (#247)
- With an `[auth]` table, a module that takes a caller gives an authenticated mock, which injects the configured authenticator call salted with the mock's name, and a `*Caller` mock, which takes the caller as an argument (#247)
- `include` appends a hand-written `<name>.fragment.compact` to a generated mock (#247)
- A file without the `// Generated by compact-mock` marker is never overwritten, and a run with any config, parse or planning error writes nothing (#247)
